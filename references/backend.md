# 后端

上游：https://github.com/fanyuantaier/wechatauto-replica
版本：1.2.4.4；对应仓库提交：91dc0e1a601013b759b261061d8f7642f736af90。
许可证：Apache-2.0。本仓库不复制上游代码；安装经过 SHA256 校验的 PyPI wheel。
wheel SHA256：2a0a81884c5ea74d04d15246d7c88ba96b0c9afcfd773b89762cefab5e09a551。

本适配器只动态加载 db/media 模块，替换日志模块，不加载顶层自动化包。
上游通过只读进程访问取得本机微信数据库读取材料，并校验数据库页；读取需要当前用户已登录的 Windows 桌面微信。后续微信版本升级可能破坏兼容性。
不支持手机独立读取、云端完整聊天历史或本机未同步消息。

文件先由原始消息中的文件名、长度、MD5定位。有完整消息 MD5 时，也识别微信下载后追加的“(1)”“(2)”等重复文件名，仍须全文哈希匹配；无 MD5 时仅匹配原文件名，并要求消息月份内候选内容一致。
图片/语音/视频使用上游的本地解码，不触发微信界面下载。合并转发由本 skill 的 forwarded.py 保留层级并逐项恢复已缓存附件，详见 [forwarded.md](forwarded.md)。图片可只有缩略图，不能把它说成原图。
发送者以 SenderName2Id 映射，展示的是联系人名，不保证是群内专用昵称。
运行状态 partial 意味着部分库缺少可用读取材料，不得声称全量读取成功。

隐私：GitHub只包含程序和skill。运行时目录必须始终在仓库外。
